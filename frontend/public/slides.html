HOW IT WORKS

The AI model stack: purpose-built per pipeline stage

Every pipeline stage is mapped to a specialized, open-weights or foundation model for maximum performance.

Stage Model / Engine Role & Execution Target Hardware
Design Audit Qwen2.5-VL / Gemini Vision Analyzes visual hierarchy, color palette, typography and copy Cloud API / Worker
Text Extraction PaddleOCR / EasyOCR Extracts text bounding boxes and content for editing & re-styling CUDA GPU / CPU
Image Generation SDXL / FLUX.2 Klein 4B Generates photorealistic themed backdrops from text prompts T4 / A100 GPU
Background Removal BRIA RMBG-2.0 / U2Net Isolates foreground product with high-precision alpha mask CUDA GPU
Edge Preservation ControlNet SDXL Canny Preserves structural product geometry during AI synthesis CUDA GPU
Layout & Export OpenCV & Pillow Text rendering, multi-platform cropping, ZIP packaging FastAPI Core CPU
Dynamic VRAM manager unloads idle models between pipeline stages, enabling full multi-model inference on a single 16GB T4 GPU.
